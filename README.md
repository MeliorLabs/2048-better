# 2048 Better

A clean, dark-mode take on the classic 2048 puzzle. Plain HTML, CSS and JavaScript. No libraries, no build step.

**Play:** open `index.html` in your browser.

## What's different
- Undo (button or Ctrl/Cmd+Z)
- Swipe controls for phones
- Best score saved between visits
- Keep playing after you hit 2048
- Arrow keys or WASD

## Run it
```
git clone https://github.com/YOUR-USERNAME/2048-better
cd 2048-better
# just open index.html
```
